# Adaptive Pass@10 evidence bundle

This compact bundle retains one canonical native simulator-success row for each of the 95 solved tasks. It is sufficient to replay task-level coverage against the fixed 120-task catalog. It does not contain failed or infrastructure rows and therefore must not be used to estimate total campaign token or wall-clock spend.

The rows comprise 67 canonical successes from the strict Standard-130
Pass@10 campaign's 120-task short subset and 28 unique native successes from
the retained adaptive residual continuation. The two task sets are disjoint.
